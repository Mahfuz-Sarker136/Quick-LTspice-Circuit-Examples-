# Quick-LTspice-Circuit-Examples-
This repo is a collection of small, ready-to-use LTspice circuits. 
Just open the .asc file, copy it, and use it.

Built for EEE students and engineers who forgot the connection and just need a quick reminder.

## Contribute

Forgot a circuit? Found a mistake?

1. Fork this repo
2. Add your circuit in a new folder
3. Make a Pull Request

If your circuit saves someone 10 minutes, it belongs here.

## Why I Made This

For remembering circuit connection in LTspice.
I don't want to watch a full YouTube tutorial just to remember one connection.
So I saved it here. For me, and for you.

Star this repo if it saved your time.
